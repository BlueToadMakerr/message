Your bots

A bot is an account a program controls: it can post in the chats you add it to, and (with a webhook or by asking) read the plain messages there. Use it to link chats with other services, such as Discord. A bot's token is its password: anyone who has it can act as the bot.

New bot

With a webhook, QuickMessage sends every new message in the bot's chats to that address (signed, see the docs). Without it the bot can just ask for new messages.

Connecting a bot

Bots are answered by your own notification & bot server (worker/), not by the web host, so this works even where the host blocks automated requests. Bots only work while that server is running (see the status above).
