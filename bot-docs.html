Bot docs

Quick start

Make a bot in Account → Bots and keep its token. In a chat open Chat options → Add one of my bots…. Your program talks to your own worker (worker/) through the database: it writes a request, the worker processes it and writes the answer. Nothing is exposed and the web host isn't involved. Bots only work while the worker runs; the Account, Bots and status pages show whether it is up.

from qmbot import QMBot      # docs/bots/qmbot.py  (pip install requests)
bot = QMBot("qmbot.bot_xxx.yyy", "https://YOURPROJECT-default-rtdb.firebaseio.com")
bot.send("CHAT_ID", "Hello!", as_name="Zed", as_pfp="https://example.com/z.png", src="Discord")
for key, ev in bot.events(bot.latest_event_key()): print(ev["message"]["from"], ev["message"]["text"])

The protocol

Request: PUT <db>/botInbox/<botId>/<reqId>.json with {token, op, ts, ...arguments} (reqId = 20-64 random characters; the database rules only accept it with the bot's real token). Answer: GET <db>/botOutbox/<botId>/<reqId>.json → {status, body} (body is a JSON string), then DELETE it. New messages: GET <db>/botEvents/<botId>/<sha256 of token>.json?orderBy="$key"&startAt="<last key>". Ops: me, setProfile, chats, members, messages, send, edit, delete (arguments as below).

Requests

RequestWhat it does
me (HTTP: GET /me)The bot's profile
setProfile {name, pfp}The bot changes its own default name / picture (https address)
chatsChats the bot is in
members {chat}Members of a chat
messages {chat, after, limit}Messages, oldest first (encrypted ones have encrypted:true and no text)
send {chat, text, as, src, replyTo, file}Post a message. as:{name,pfp} changes the name/picture for that message; src says where it came from
edit {chat,id,text}, delete {chat,id}Edit / delete the bot's own messages

Who posted what

Every bot message carries botId. With as the chat shows another name and picture, plus a BOT badge with the real bot's name and the src. People can't write these fields, so a bot's identity can't be faked. This is how you link a chat with Discord: post each Discord message as that Discord user.

Webhook

Instead of reading the event feed you can set an https address on the bot (Edit) and each new message in its chats is POSTed there as {event, bot, chat, message} with X-QM-Signature (HMAC-SHA256 of the body; key = SHA-256 hex of your token).

Limits and safety

20 posts per 10 seconds, 4000 characters. Bots can't read end-to-end encrypted messages and what they post in an encrypted chat isn't encrypted. The token is the bot's password: only add bots you control, and make a new token if one leaks. A ready-made Discord bridge is in docs/bots/discord_bridge.py.
